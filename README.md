# DeteccionRopa

Para correr desde VSCode (terminal linux)
- cd src/DeteccionRopa/build
- ./DeteccionRopa

https://github.com/kritanjalijain/Clothing_Detection_YOLO

Detecta:
- bag
- belt
- boots
- footwear
- outer
- dress
- sunglasses
- pants
- top
- shorts
- skirt
- headwear
- scarf/tie

pip install ultralytics opencv-python
